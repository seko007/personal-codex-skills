# 契約の横断確認

変更した業務概念を、入力から利用者へ返すまで追う。以下は関連するものだけ確認する。

| 観点 | 確認内容 |
| --- | --- |
| 入力 | キー、ネスト、型、必須、未指定、null、空文字、正規化 |
| 認可・検索 | 所属境界、可視範囲、AND/OR、演算子、保存済み条件、一括処理 |
| 保存 | 保存値、補助情報、DB制約、更新・削除、履歴、重複判定 |
| 返却 | 取得列、一覧・詳細、ネスト、null、並び順、ページング |
| 集計 | 対象母集団、集計軸、率の分母、上位件数、その他行、丸め |
| 周辺経路 | プレビューと本実行、CSV入出力、バッチ、UIの選択肢 |
| 環境反映 | 新規初期化、既存環境の移行、実行時マスタ、切替順序 |

「既存と同様」は名前ではなく実際のリクエスト・レスポンスと挙動で比較する。代表例を一つ示し、相違点と未確認点を分ける。

検索条件を受け付けることだけで、一覧レスポンスに項目が含まれると判断しない。初期データ定義があることだけで、稼働済み環境への反映が完了したと判断しない。

互換処理の必要性は、利用中のクライアント、配布済みテンプレート、既存データ、切替計画で判断する。未稼働機能の架空の旧データを前提にせず、実在する契約は根拠なく壊さない。
