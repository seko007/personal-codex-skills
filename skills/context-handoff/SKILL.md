# Context Handoff

調査後、実装前、検証後、独立レビュー前などの節目で、新しいチャットへ移る価値があるか判断する。小さい継続作業には使わない。

内部の残りトークン数や見えないコンテキスト使用量を推測しない。蓄積した調査量、次のフェーズの独立性、残り作業の小ささで判断する。

- 残りが小さく、会話内の詳細に依存する場合は継続を勧める。
- 短い記録から次のフェーズを始められる場合は新しいチャットを勧める。
- 理由を一つ示し、チャットを切り替えるかはユーザーに任せる。提案だけを理由に依頼された作業を中断しない。

引継ぎ記録は、記録作成が依頼範囲または利用先の規約に含まれる場合に既存の作業メモへ追加する。適切な保存先がなく文書作成が必要なら、配置規約に沿って候補を示す。それ以外はチャットで貼り付け可能な引継ぎを返す。

記録に含めるのは、目的と現在フェーズ、確定要件・決定と根拠、変更ファイルと検証結果、残作業・未決事項、次に読む最小限の資料だけにする。長いログ、全文差分、会話の再録は避け、参照先を示す。

次のチャット用の開始文も用意し、引継ぎの場所と次の作業範囲を明記する。調査完了を実装開始の許可と書き換えない。
